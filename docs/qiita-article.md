## はじめに

Mac で Magic Keyboard と Magic Trackpad を使っていると、キーボードとトラックパッドが別々に置いてあるため、**両手を行ったり来たりさせる**場面がよくあります。

たとえばブラウザーで調べものをしているとき、

- ページを見ながらトラックパッドでスクロールしていて、再読み込みしたくなったら、キーボードに手を伸ばして ⌘R
- タブを切り替えるたびに、またキーボードへ
- ページを戻る・進むときは、ポインターを画面の左上まで動かして、ブラウザーの「戻る」「進む」ボタンをクリック

と、よく使う操作ほど、キーボードとの往復や、ボタンまでポインターを動かす手間がかかり、地味に面倒でした。

そこで、**よく使うブラウザーの操作を、Magic Trackpad だけで済ませられるように**しようと思って作ったのが、**rexTrackpad** です。3本指・4本指のタップや、指で円を描く動きで、Google Chrome・Safari・Microsoft Edge・Firefox を操作できます。**macOS の既存のジェスチャーを変えずに使える**ことを大事にしています。Mac のメニューバーに常駐するアプリで、無料（MIT ライセンスの OSS）で使えます。

もちろん、MacBook の内蔵トラックパッドでも使えます。

https://github.com/rex0220/rexTrackpad

![rexTrackpad の設定画面（割り当てタブ）](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/100572/e77d0741-ee59-47e6-b535-0942786550df.png)

## できること

### macOS の設定を変えずに使えるジェスチャー（おすすめ）

rexTrackpad は、**macOS のいつもの操作に影響しないジェスチャー**を中心にしています。インストールしてすぐ、次のジェスチャーが使えます。

| ジェスチャー | 初期設定の操作 |
|---|---|
| 3本指でタップ（中央） | 再読み込み |
| 3本指でタップ（左側 / 右側） | 前のタブ / 次のタブ（タブ移動） |
| 3本指でタップ（上端） | ページの先頭へ |
| 3本指でタップ（左下の隅 / 右下の隅） | 1 画面上へ / 1 画面下へ |
| 4本指でタップ | ポインターの下のリンクを新しいタブで開く |
| 1本指で円を描く（時計回り / 反時計回り） | 閉じたタブを開き直す / タブを閉じる |

タップは、macOS 標準のジェスチャーと重なりません。1本指の円は、ふだんのポインター移動と区別できるよう、「ほぼ1周、丸く描く」ときだけ反応します。

3本指のタップは、トラックパッドを **3×3 の区域**に分けて、タップした場所ごとに別の操作を割り当てられます。初期設定では、左側・中央・右側・上端・左下・右下の6つを使っています。**左上・右上の隅と下端**は空いているので、好きな操作を割り当てられます（たとえば下端に「ページの最後へ」）。

### 選べる操作

どのジェスチャーにも、次の操作を自由に割り当てられます。

- 再読み込み / 強制再読み込み
- 前のタブ / 次のタブ / 新しいタブ / タブを閉じる / 閉じたタブを開き直す
- 戻る / 進む
- リンクを新しいタブで開く（ポインターの下のリンク）
- ページの先頭へ / ページの最後へ / 1 画面上へ / 1 画面下へ

そのほかの特徴です。

- **ブラウザー以外のアプリが前面にあるときは何もしません。** ほかのアプリの操作を邪魔しません。
- ブラウザーごとにオン/オフできます。
- ジェスチャーが効くと、ポインターの近くに操作を表す小さな記号が一瞬表示されます（オフにもできます）。
- メニューや設定画面は日本語で表示されます（macOS の言語設定に従います）。

### macOS の設定を変えると使えるジェスチャー（おまけ）

3本指・4本指のスワイプや、3本指で円を描くジェスチャーにも対応しています。ただし、これらは macOS 標準の Mission Control やデスクトップの切り替えと同じ動きです。使うには macOS 側の設定を変える必要があるので、初期状態では自動で無効になっています（詳しくは後述）。

私自身は、慣れた macOS の操作を変えたくないので、これらは使っていません。

## 動作環境

- macOS 13 Ventura 以降
- Apple Silicon（M1 以降）・Intel Mac のどちらでも動きます
- 内蔵トラックパッド、または Magic Trackpad

## インストール

### 1. ダウンロードして、アプリケーションフォルダーに入れる

[Releases のページ](https://github.com/rex0220/rexTrackpad/releases) から、いちばん新しい `rexTrackpad-<バージョン>.zip` をダウンロードします。ダブルクリックで展開し、出てきた `rexTrackpad.app` を**アプリケーション**フォルダーに移動します。

### 2. 初回だけ「このまま開く」で起動する

rexTrackpad は、Apple の公証（有料の開発者登録が必要な審査）を受けていません。そのため、初回の起動は macOS にブロックされます。次の手順で起動してください。

1. `rexTrackpad.app` をダブルクリックします。「“rexTrackpad”は開かれていません」と表示されたら、**完了**を押します。
2. **システム設定 › プライバシーとセキュリティ**を開き、下の「セキュリティ」までスクロールします。
3. 「お使いの Mac を保護するために“rexTrackpad”がブロックされました。」というメッセージの横にある**このまま開く**を押します。

   ![システム設定の「このまま開く」ボタン](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/100572/ba37cdc7-c447-46f6-b017-69919c056706.png)

4. もう一度**このまま開く**を押し、パスワードなどで認証します。

2回目以降は、ふつうに起動できます。

:::note info
配布している zip は、GitHub 上で公開しているソースコードから自動でビルドしたものです。各リリースには、ファイルが改ざんされていないことを確かめるためのチェックサム（`.sha256`）も付けています。
:::

### 3. アクセシビリティを許可する

起動すると、「アクセシビリティ」の許可を求めるダイアログが出ます。**システム設定を開く**を押し、一覧の **rexTrackpad** をオンにしてください。

![アクセシビリティの一覧で rexTrackpad をオンにする](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/100572/0400825f-8043-4e7b-b1c3-67cef28234fc.png)

ブラウザーにキー操作（⌘R など）を送るために必要な権限です。これがないと、ジェスチャーを認識しても何も起きません。

### 4. ログイン時に自動で起動する（任意）

メニューバーの手のアイコンをクリックし、「**ログイン時に起動**」を選ぶと、Mac にログインしたときに自動で起動します。

## 使い方

### メニュー

メニューバーの手のアイコンをクリックすると、メニューが開きます。

![rexTrackpad のメニュー](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/100572/5487be7b-9fa0-4483-8e65-69baab9d73cf.png)

- **有効**：オフにすると、rexTrackpad の動作をすべて止めます。一時的に使いたくないときに便利です。
- **設定…**：ジェスチャーの割り当てなどを変える画面を開きます。

### 設定画面

メニューの「設定…」を開くと、4つのタブがある設定画面が出ます。閉じるときは、右下の「閉じる」ボタン、esc キー、⌘W のどれでも閉じられます。

#### 割り当て

ジェスチャーごとに、ポップアップから操作を選びます。選んだらすぐに反映されます（記事の冒頭の画像がこのタブです）。macOS 標準のジェスチャーと重なるものには「⚠︎ macOS と重複」と表示され、自動で無効になります。

いちばん上の **3本指タップ**は、トラックパッドと同じ並びの 3×3 のマスで選びます。マスごとに、そこをタップしたときの操作を選んでください。何も割り当てていない隅は「左側と同じ」「右側と同じ」、上端・下端は「中央と同じ」として動くので、使わない場所はそのままで大丈夫です。

一覧の下にある「**ジェスチャーが効いたら、ポインターの近くに記号を表示**」で、記号の表示をオン/オフできます（下の「ジェスチャーが効いたことの表示」を参照）。

#### 感度

タップやスワイプ、円の判定の細かい調整です。反応しにくい・反応しすぎるときに使います。元に戻すときは「感度を初期設定に戻す」を押します。

「タップ」の欄には、3本指タップの区域の図があります。3本指でタップすると、**タップした位置が図に点で表示され、どの区域と判定されたか**（「最後のタップ: 左上の隅」など）が分かります。狙った区域にならないときは、「左右の区域の幅」「上下の区域の高さ」で区域の大きさを調整してください。図の線もすぐに変わります。

![設定画面（感度タブ）](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/100572/4bc41949-7053-4fa0-9c19-986b92f3bee0.png)

#### ブラウザー

ブラウザーごとに、ジェスチャーを使うかどうかを切り替えます。

![設定画面（ブラウザータブ）](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/100572/3bf3fd34-7594-473b-81ae-b269cd742932.png)

#### 権限

アクセシビリティが許可されているか、トラックパッドの入力が届いているかを確認できます。うまく動かないときは、まずここを見てください。画面の下には、アップデートしてジェスチャーが効かなくなったときの対処が書いてあります（下の「アップデート」も参照）。

![設定画面（権限タブ）](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/100572/71188040-7eb2-49a9-979c-589fe0aa2ec9.png)

### ジェスチャーが効いたことの表示

ジェスチャーでブラウザーを操作すると、**ポインターの右下に、操作を表す小さな記号が一瞬（約 0.7 秒）表示**されます。反応したかどうかが、目線を動かさずに分かります。

表示される記号は、操作ごとに次のとおりです。

<img src="https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/100572/86c046e8-f445-49ba-b132-eb05bedc0b13.png" alt="操作ごとに表示される記号の一覧" width="265">

- 記号は半透明で、後ろのページがうっすら見えます。
- クリックは記号を素通りし、ブラウザーのフォーカスも奪わないので、そのまま操作を続けられます。
- 記号はブラウザーに操作を送った後に出すので、操作が遅くなることはありません。
- ブラウザー以外のアプリが前面のときや、macOS と重複して無効になっているジェスチャーでは表示されません。

気になる場合は、設定 › 割り当てタブの「ジェスチャーが効いたら、ポインターの近くに記号を表示」をオフにしてください。

### ジェスチャーのコツ

- **タップ**：指を置いてすぐ離します。押し込むクリックではなく、軽く触れるだけです。
- **左側・右側のタップ**：トラックパッドの左側を3本指でタップすると前のタブ、右側だと次のタブに移ります。左側・右側は、左端・右端からそれぞれ幅の3分の1くらいの範囲で、真ん中あたりをタップすると再読み込みです。
- **隅・上端・下端のタップ**：3本の指の真ん中が、トラックパッドの隅や上端・下端に来るようにタップします。指を広げると真ん中が内側に寄るので、指をそろえて端に寄せるのがコツです。うまく判定されないときは、設定 › 感度タブの図で位置を確かめてください。
- **ページの先頭へ・ページ送り**：キーボードの Home / End / Page Up / Page Down と同じ動きです。検索欄などの入力欄にカーソルがあるときは、ページではなく入力欄の中でカーソルが動きます。その場合は、ページの本文を一度クリックしてから使ってください。
- **リンクを新しいタブで開く**：リンクの上にポインターを合わせてから、4本指でタップします。
- **1本指の円**：トラックパッドの高さの4分の1くらいの大きさで、約1秒かけて**1周**描き、指を離します。ポインターを動かしてから、指を離さずにそのまま描いても大丈夫です。描いている間は、ポインターも一緒に動きます。
- **円の向き**：時計回りが「閉じたタブを開き直す」、反時計回りが「タブを閉じる」です。ほかの操作（戻る・進むなど）にしたいときは、設定 › 割り当てタブで変えられます。

## （おまけ）3本指のスワイプを使いたい場合

macOS の初期設定では、3本指・4本指のスワイプは **Mission Control** や**デスクトップの切り替え**などに使われています。

rexTrackpad は、ふだんの Mac の操作を邪魔しないことを最優先にしています。そのため、**macOS が使っているジェスチャーは自動で無効にしています**。設定画面の割り当てタブでは、そうしたジェスチャーに「⚠︎ macOS と重複」と表示されます。

それでも3本指のスワイプや円を使いたい場合は、macOS 側のジェスチャーを4本指に移します。**Mission Control などの操作が4本指に変わる**ので、慣れた操作を変えてもよい場合だけにしてください。

1. **システム設定 › トラックパッド › その他のジェスチャ**を開きます。
2. 「フルスクリーンアプリケーション間をスワイプ」を「**4本指で左右にスワイプ**」にします。
3. 「Mission Control」を「**4本指で上にスワイプ**」、「App Exposé」を「**4本指で下にスワイプ**」（またはオフ）にします。

これで3本指のスワイプと円が使えるようになります。4本指のスワイプ（戻る/進む）は macOS 側が使うので、無効のままです。

| ジェスチャー | 初期設定の操作 |
|---|---|
| 3本指で左右にスワイプ | 前のタブ / 次のタブ |
| 3本指で上下にスワイプ | 新しいタブ / タブを閉じる |
| 3本指で円を描く（時計回り / 反時計回り） | 閉じたタブを開き直す / 強制再読み込み |

## うまく動かないとき

| 症状 | 確認すること |
|---|---|
| ジェスチャーをしても何も起きない（記号も出ない） | ブラウザーが前面にあるか。メニューの「有効」にチェックが入っているか。ジェスチャーが認識されていない可能性もあるので、動きを少し大きく・はっきりさせてみてください。 |
| 記号は出るのに、ブラウザーが反応しない | 設定 › **権限**タブで、アクセシビリティが「許可済み」になっているか。アップデート直後なら、下の「アップデート」の手順で許可し直してください。 |
| 特定のジェスチャーだけ動かない | 設定 › 割り当てタブで、操作が「なし」になっていないか。「macOS と重複」になっていないか（上の「（おまけ）3本指のスワイプを使いたい場合」を参照）。 |
| ページの先頭へ・ページ送りでページが動かない | 入力欄にカーソルがないか。ページの本文を一度クリックしてから試してください。チャット欄など、ページの中で別にスクロールする部分をクリックした後は、その部分がスクロールします。 |
| 特定のブラウザーだけ動かない | 設定 › **ブラウザー**タブで、そのブラウザーにチェックが入っているか。 |
| 反応しにくい / 反応しすぎる | 設定 › **感度**タブで調整します。元に戻すときは「感度を初期設定に戻す」を押します。 |
| Safari で強制再読み込みが効かない | Safari の設定 › 詳細 で「Web デベロッパ用の機能を表示」をオンにしてください。 |

## アップデート

1. メニューの「終了」で rexTrackpad を終了します。
2. 新しい zip をダウンロードし、アプリケーションフォルダーの `rexTrackpad.app` と置き換えます。
3. 起動します。もう一度「このまま開く」が必要な場合があります。

アップデート後は、macOS が rexTrackpad を別のアプリとして扱うため、アクセシビリティの許可が外れて、ジェスチャーが効かなくなります。次の手順で許可し直してください。

1. **システム設定 › プライバシーとセキュリティ › アクセシビリティ**を開きます。
2. 一覧の **rexTrackpad** を選んで、下の **−** ボタンで削除します。
3. rexTrackpad を開き直します。許可を求めるダイアログが出るので、**システム設定を開く**を押し、一覧の rexTrackpad をオンにします。

ターミナルを使う場合は、手順1〜2の代わりに次を実行してから、rexTrackpad を開き直してください。

```bash
tccutil reset Accessibility com.rex0220.rexTrackpad
```

## アンインストール

1. メニューで「ログイン時に起動」をオフにし、「終了」を選びます。
2. アプリケーションフォルダーの `rexTrackpad.app` をゴミ箱に入れます。
3. 権限と設定も消す場合は、ターミナルで次を実行します。

```bash
tccutil reset Accessibility com.rex0220.rexTrackpad
defaults delete com.rex0220.rexTrackpad
```

## プライバシーについて

- rexTrackpad が読み取るのは、**トラックパッドのタッチ**と、**前面にあるアプリの種類**だけです。
- キーボードの入力内容、パスワード、閲覧中の URL や履歴、ページの内容は、読み取りも記録もしません。
- ネットワークには一切接続しません。

:::note warn
トラックパッドのタッチを読み取るために、Apple が公開していない仕組み（非公開 API）を使っています。そのため、macOS のアップデートで動かなくなる可能性があります。その場合は、新しいバージョンをお待ちください。
:::

## おわりに

Magic Keyboard と Magic Trackpad を行き来する手間を減らしたくて作りました。今では、ページを読んでいる間はほとんどトラックパッドだけで、再読み込み、タブの移動・閉じる・開き直す、ページの先頭への移動やページ送りまで済ませられるようになりました。

同じように「キーボードに手を伸ばすのが面倒」と感じている方は、ぜひ試してみてください。
